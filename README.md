# GIF MOSAIC — GitHub Pages

정적 HTML/CSS/JavaScript 사이트입니다. Python이나 서버 설치 없이 GitHub Pages에서 작동합니다.

## 사용
1. GitHub 저장소의 루트에 `index.html`, `app.js`, `palette.json`, `assets/`, `.nojekyll`을 올립니다.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`를 선택합니다.
3. 배포된 주소에 접속하여 **동영상 파일 열기**로 MP4(H.264) 또는 WebM을 선택합니다.
4. 재생/탐색/음량/타일 개수/색상 반영/전체 화면을 조절합니다.

동영상은 서버에 업로드되지 않고 사용자의 브라우저에서만 처리됩니다. 영상 재생은 브라우저의 코덱 지원 및 자동재생 정책에 따릅니다.

참고: 제공된 이미지 모음에서 추출한 정적 WebP 타일을 사용합니다. GIF 원본의 프레임별 애니메이션을 개별 타일에 재생하는 기능은 포함하지 않습니다.
